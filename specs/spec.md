# 規格｜手勢音樂粒子秀

## 目標
打開網頁就能用鏡頭玩粒子和音樂：伸出食指移動時粒子會跟著移動，比出 1、2、3、4、5 會分別換成五種不同的形狀，握拳一次音樂就換下一首。沒有鏡頭或不開鏡頭時，改用滑鼠也能完成移動粒子、換五種形狀和切換音樂這三件事。

## 檔案與介面（驗收會用到，名稱不可改）
```
index.html        入口，用 <script type="module" src="js/app.js"> 載入
js/config.js      已經放好，照它的內容做，不要改它
js/gesture.js     只放手勢判斷，不可以碰畫面與鏡頭（終端機也要能 import）
js/app.js         把鏡頭、手勢、粒子、音樂接起來；其他檔案可以自己分
```
js/gesture.js 要 export：
- `countFingers(landmarks)`：landmarks 是手的 21 個點（每個點有 x、y，0～1）。回傳伸出幾根手指 0～5；不是 21 個點或座標不是數字時回傳 null。
  手會轉向任何方向，所以不要用「指尖比關節高」判斷，改用距離：四指看「指尖(8、12、16、20)到手腕(0)」是否大於「第二關節(6、10、14、18)到手腕」的 1.22 倍；
  拇指看「指尖(4)到小指根(17)」是否大於「拇指關節(3)到小指根(17)」的 1.05 倍。（真實照片實測：伸直約 1.3 以上，彎曲 1.15 以下。）
- `class GestureSmoother`：`new GestureSmoother(幾格)`、`add(n)`（n 為 null 時略過）、`value`（最近幾格出現最多的數字，沒有資料是 null）。
- `class FistHold`：`new FistHold(秒數)`、`update(t, 是否握拳)`：握滿秒數的那一格回傳 true，握著不放不再回傳 true，放開後才能再觸發。
- `shapeFor(fingers, table)`：fingers 是 1～table.length 的整數時回傳 table[fingers-1]，其他（0、null、小數、超出）回傳 null。

網頁要提供 `window.__show`：
- `state()` 回傳 `{ mode, fingers, shape, playing, particles, theme, title }`；mode 是 'camera' 或 'mouse'；shape 是 config 裡的英文名稱；particles 是粒子數量。
- `feed(t, fingers, x, y)`：送進一格手勢（t 秒、手指數、0～1 的位置）。鏡頭、滑鼠、驗收都要走同一條處理路徑：平滑後換形狀、握拳計時切換音樂。
- 網址帶 `?test=1` 時：不開鏡頭、不顯示開始畫面、mode 為 'mouse'，而且不自動送滑鼠的手勢（只接受 feed）。

其他規定：
- 手部辨識只用 vendor 資料夾：`vendor/vision_bundle.mjs`（HandLandmarker，runningMode 'VIDEO'，numHands 2）、`vendor/wasm/vision_wasm_internal.js` 與 `.wasm`、`vendor/hand_landmarker.task`。不可以連 CDN。
- 粒子用 Canvas 2D 畫在全螢幕的 canvas 上（驗收會讀這張畫布的像素）；形狀名稱：sphere heart star galaxy firework spiral snow dna butterfly infinity note。
- 鏡頭畫面左右相反（像照鏡子），手往右，粒子也往右。
- 音樂用瀏覽器的 Web Audio 直接合成，不用外部音檔。瀏覽器規定要按過按鈕才能出聲，所以要有「開始」畫面，上面兩個按鈕：使用鏡頭、沒有鏡頭用滑鼠玩。
- 鏡頭打不開（沒有鏡頭、沒給權限、被別的程式佔用）：畫面顯示原因，自動改成滑鼠模式。滑鼠模式：移動＝食指，按 1～5＝手指數，按住空白鍵＝握拳。
- 畫面上要有：標題（config.title）、目前手指數、形狀、音樂狀態、手勢對照表、一行「影像只在這台電腦處理，不上傳、不存檔」。全部繁體中文。
